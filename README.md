## What is SmyVolt?

SmyVolt is a collection of my electrical engineering work. Each project has its own folder with the code, a demo notebook and a short explanation of the theory behind it.

---

## Projects

| Project | Area | Description |
|---------|------|-------------|
| [Balanced Three-Phase Analyser](circuit_analysis) | Power systems | Solves balanced three-phase circuits with wye and delta loads, giving phase current, power (S, P, Q), power factor and a voltage/current plot |

More projects will be added here as I finish them.

---

## Installation

```bash
git clone https://github.com/simbarashekamwara/SmyVolt.git
cd SmyVolt
pip install -r requirements.txt
jupyter lab
```

### Dependencies

| Library | Purpose |
|---------|---------|
| `numpy` | Arrays and complex number maths |
| `scipy` | Numerical methods |
| `sympy` | Symbolic maths |
| `matplotlib` | Plots and phasor diagrams |
| `jupyterlab` | Notebooks |
